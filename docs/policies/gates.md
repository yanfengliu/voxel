# Gates in detail (voxel)

Each paragraph here is a paragraph of the Gates section of [AGENTS.md](../../AGENTS.md) in full; AGENTS.md keeps its opening. The rest moved here from AGENTS.md, sentence for sentence, on 2026-10-29.

Toolchain: Node 24, pinned in `.nvmrc`. CI runs the complete `npm run verify` — browser suite included — on Node 24 across Linux and Windows, and a portable subset (unit tests, typecheck, lint, build, public API, core-only package) on Node 22, so the older major a consumer may still be on stays proven without the baseline's own gate being the one that never runs.

A local green run is not evidence about CI. The browser lane fails on hardware slower than this workstation and on nothing else, so every browser budget is sized from a measurement of the test it guards — the suite default in `playwright.config.ts` from the slowest test that uses it, plus the allowance `tests/testing/test-timeout.ts` charges for a machine that is not the author's, plus a measured margin for what a slow host does to the work; a test heavier than that declares its own `test.setTimeout()` with its measurement beside it. There is deliberately no `process.env.CI` branch, because a budget only CI executes is the same defect again. `tests/testing/browser-timeout-headroom.ts` fails a passing run whose slowest test has spent over 75% of its budget, so a test is reported while it is still merely close — which is where it is visible, since the test that took CI down had been running at 88% of its budget on this machine. Read the remote run's result rather than assuming it matches the local one. (Established 2026-08-28, after five weeks of red CI behind green local gates; see [docs/learning/defect-register.md](../learning/defect-register.md).)
