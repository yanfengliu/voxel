## Approach

Preserve existing default semantics and replay compatibility. New public options are additive, independently reviewed, surface-pinned, and versioned as minor releases. No runtime dependencies, no history rewriting, no deployment. A literal requested mechanism is not sufficient: its advertised property must be proved, and a safer existing API may retire a stale request.

Use current engine recording, replay, occupancy, and profiling tools before new probes. Every milestone has TDD contract cases and a deliberate red mutation for its principal regression class. Measurements require equal work and matching semantic state. Raw runs live only in ignored tmp paths; authored plans and every review report remain under this work folder or the milestone's separately allocated folder.

The root orchestrator owns the shared expensive-gate CPU slot. No full engine gate, build, or heavy benchmark starts until it releases the slot. Each engine milestone uses `npm run gates` before any code commit and push, then is merged to main, pushed, and followed through remote matrix and publish-dist. The game adopts a new tarball only after that boundary is green.

### Proposed first additive contract

`SelfCheckResult` gains an optional-on-type, always-returned coverage field for old consumer mocks/constructors to stay assignable. It includes the declared replay horizon, nonempty checked ranges, uncovered ranges with explicit reasons, enabled checks and completeness. Existing ok keeps its divergence-only meaning. Ranges describe transitions `(fromTick,toTick]`, matching self-check state/event/execution comparison. A disabled comparison is not silently claimed checked. No payload and zero segments remain distinguishable no-op outcomes. Tail completeness does not require adding expensive replay work; it describes what the existing checker actually compared. Root approval and exact surface fixture review precede code.

Runner advance is a second milestone, not bundled invisibly: optional synchronous `advance(world)` defaults to step and must execute exactly one tick. A matching replayer advance hook is required for bundles produced by a bridge whose work surrounds world.step. Errors from an unpoisoned wrapper must not be mislabeled poisoned; proposed additive advanceError result contract needs agreement first.
